# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is an interactive Business Intelligence project developed using Microsoft Power BI. The project analyses employee attrition, job satisfaction, compensation, work-life balance, departmental trends, and workforce demographics.

## Project Objectives

- Identify key factors contributing to employee attrition.
- Analyse relationships between job satisfaction and employee turnover.
- Examine salary and compensation patterns.
- Compare attrition across departments and geographical regions.
- Provide HR managers with data-driven insights for employee retention.

## Technologies Used

- Microsoft Power BI
- DAX
- SQL
- GitHub
- Excel
- CSV

## Dashboard Pages

1. Executive Workforce Insights
2. Attrition Drivers & Behavioural Analytics
3. Compensation & Performance Parity
4. Filter Workspace & Granular Data Audit
