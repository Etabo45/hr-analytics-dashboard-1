# HR Analytics Dashboard User Guide

## Overview

The HR Analytics Dashboard is an interactive Power BI solution designed to help HR teams analyse employee attrition and workforce trends.

## Dashboard Pages

### 1. Executive Workforce Insights
Provides high-level KPIs and workforce overview.

### 2. Attrition Drivers & Behavioural Analytics
Analyses factors that may contribute to employee attrition.

### 3. Compensation & Performance Parity
Examines salary, performance, and employee retention.

### 4. Filter Workspace & Granular Data Audit
Allows users to filter employee data and perform detailed analysis.

## How to Use

1. Open the Power BI dashboard.
2. Select the required dashboard page.
3. Use the available filters and slicers.
4. Select charts to cross-filter the data.
5. Analyse the displayed workforce trends.
