# Data Dictionary

| Column | Description |
|---|---|
| EmployeeID | Unique employee identification number |
| Age | Employee age |
| Gender | Employee gender |
| Department | Department where employee works |
| JobRole | Employee's job role |
| JobLevel | Employee's job level |
| MonthlyIncome | Employee's monthly income |
| JobSatisfaction | Employee job satisfaction rating |
| YearsAtCompany | Number of years employee has worked at the company |
| YearsInCurrentRole | Number of years in current role |
| YearsSinceLastPromotion | Number of years since last promotion |
| Attrition | Indicates whether employee left the company |
